# خطوات ربط الموقع بقاعدة بيانات Supabase

اتبعي هاي الخطوات بالترتيب (مرة وحدة بس، أول ما تجهزي).

## 1. إنشاء حساب ومشروع على Supabase
1. روحي لـ [supabase.com](https://supabase.com) واعملي حساب مجاني (فيه دخول بـ GitHub أو إيميل).
2. اضغطي **New Project**.
3. اختاري اسم للمشروع (مثلاً `ciphera-store`) وكلمة مرور لقاعدة البيانات (احفظيها بمكان آمن).
4. استنّي دقيقة لين يجهز المشروع.

## 2. إنشاء جدول المنتجات
1. من القائمة الجانبية بالمشروع، افتحي **SQL Editor**.
2. اضغطي **New query**.
3. افتحي ملف `database/schema.sql` من هاد المجلد، انسخي كل محتواه، والصقيه بالمحرر.
4. اضغطي **Run**. هيك انعمل جدول `products` بكل الحماية المطلوبة.

## 3. تعبئة المنتجات الحالية (227 منتج)
1. بنفس الـ SQL Editor، افتحي query جديدة.
2. افتحي ملف `database/seed_products.sql`، انسخي كل محتواه، والصقيه.
3. اضغطي **Run**. هيك كل منتجاتك الحالية (يلي كانت بالـ HTML) رح تنزل على قاعدة البيانات مباشرة، بنفس الأسعار والصور والأصناف.

> ملاحظة: الصور نفسها ظلت بمجلد `image/` بنفس المكان القديم، إحنا بس نقلنا "المعلومات" (الاسم، السعر، مسار الصورة...) على قاعدة البيانات. لسا لازم ترفعي مجلد `image/` كامل لاستضافة الموقع متل ما كان.

## 3.5. إنشاء جدول الطلبات (orders) — لنظام الدفع عبر واتساب
1. بنفس الـ SQL Editor، افتحي query جديدة.
2. افتحي ملف `database/orders_schema.sql`، انسخي كل محتواه، والصقيه.
3. اضغطي **Run**. هيك انعمل جدول `orders` يلي بيسجل فيه كل طلب بيوصل من الزبائن، حتى قبل ما يوصل عالواتساب.

## 4. عمل حساب دخول للوحة التحكم (Admin)
1. من القائمة الجانبية: **Authentication > Users**.
2. اضغطي **Add user** → **Create new user**.
3. حطي إيميلك وكلمة مرور قوية (هاد هو الحساب يلي رح تدخلي فيه على `admin.html`).
4. تأكدي إنو خيار **Auto Confirm User** مفعّل (عشان ما يطلب تأكيد إيميل).

## 5. ربط الموقع بالمشروع
1. من القائمة الجانبية: **Project Settings > API**.
2. انسخي القيمتين:
   - **Project URL**
   - **anon public** (تحت API Keys)
3. افتحي ملف `js/supabase-config.js` بالموقع، وحطي القيمتين مكان:
   ```js
   const SUPABASE_URL = 'ضيفي-رابط-مشروعك-هون';
   const SUPABASE_ANON_KEY = 'ضيفي-مفتاح-anon-public-هون';
   ```
4. احفظي الملف وارفعيه على الاستضافة متل باقي ملفات الموقع.

## 6. جربي!
- افتحي أي صفحة صنف (مثلاً `bags.html`) — المفروض المنتجات تطلع من قاعدة البيانات مباشرة.
- افتحي `admin.html`، سجلي دخول بالإيميل وكلمة المرور يلي عملتيهم بخطوة 4.
- جربي تضيفي منتج جديد، أو تعدلي سعر، أو تحذفي منتج خلص عندك، وشوفي إنو التغيير بيظهر فوراً بالموقع.

---

## كيف تضيفي منتج جديد من هلأ وطالعة؟
1. ارفعي صورة المنتج لمجلد `image/` بالاستضافة (متل ما كنتي عم تعملي).
2. افتحي `admin.html` وسجلي دخول.
3. عبّي النموذج فوق: الاسم، السعر، مسار الصورة (نفس المسار يلي رفعتيه فيه)، الصنف، وأي إعدادات ثانية.
4. اضغطي **إضافة المنتج** — خلص، صار موجود بالموقع.

## كيف تحذفي منتج خلص عندك؟
افتحي `admin.html`، لاقي المنتج بالجدول، اضغطي 🗑 وأكدي الحذف.

(بديل عن الحذف: لو بس بدك تخفيه مؤقتاً بدون ما تحذفيه نهائي، فكي علامة "متوفر بالمخزون" من نموذج التعديل ✎ بدل ما تحذفيه.)

## نظام الطلبات عبر واتساب (بدون تسجيل دخول للزبون)
- الزبون بيضيف منتجات للسلة (بتنحفظ بمتصفحه هو بس، localStorage).
- لما يضغط "إتمام الشراء"، بيعبي اسمه ورقمه وعنوانه بفورم صغير جوا السلة.
- النظام بيسوي شيئين بنفس اللحظة:
  1. بيحفظ نسخة كاملة من الطلب بجدول `orders` بقاعدة البيانات (نسخة احتياطية عندك، تقدري تشوفيها من `admin.html`).
  2. بيفتح واتساب مباشرة مع رسالة جاهزة فيها كل تفاصيل الطلب (المنتجات، الكميات، الأسعار، الإجمالي، بيانات الزبون)، مرسلة لرقم المتجر **970594908375**.
- إنتِ بتكملي الدفع والتوصيل يدوياً عن طريق المحادثة عالواتساب متل العادة.
- تقدري تتابعي كل الطلبات وتغيّري حالتها (قيد الانتظار / تم التأكيد / تم التوصيل / ملغي) من قسم "الطلبات الواردة" جوا `admin.html`.
